# Brückenbild

`board.png` im README des Repositorys ist ein Bildschirmfoto der [Flottenbrücke](../../flottenbruecke/README.md)
mit den Beispieldaten aus `flottenbruecke/beispiel/bericht.json` (1440 × 900 px). Neu aufnehmen:
die Brücke lokal auf einem freien Port starten (`BRUECKE_DB` auf eine Wegwerfdatei), den Bericht
mit frischem `stand` posten (sonst wird das Projekt grau), Seite im Browser in 1440 × 900 aufnehmen,
Brücke wieder stoppen.
