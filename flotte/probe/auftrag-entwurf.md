# Mission: Probe des Auftragsschreibers

Eine Mission zum Ausprobieren von `flotte auftrag`. Jedes Missionsziel legt eine neue Datei an;
nach der Probe werden die Issues geschlossen.

# Missionsziel: Datei `probe/a.md` anlegen

## Was
Neue Datei `probe/a.md` mit einer Zeile Text.

## Abnahmekriterien
- `probe/a.md` existiert und enthält eine Zeile.

## Verifikationsweg
Datei im Pull Request ansehen.

## Betroffene Module
- `probe/`
